# Support

## Usage questions

Read the [user guide](docs/user-guide.md), [verification guide](docs/verification.md), and current
[release notes](https://github.com/internalforces/BenfordLens/releases/latest) first. If the
question remains, open a GitHub issue using the most relevant form.

When reporting a problem, include the application version, operating system, installation method,
expected behavior, and observed behavior. Reproduce data-related problems with a small synthetic
file. Never upload a real or sensitive dataset.

## Project boundary

Benford Lens is a local exploratory analysis tool. It provides distribution comparisons and
reference statistics, but it does not decide whether Benford's Law applies to a dataset and does
not provide legal, accounting, audit, or investigative conclusions.

The project currently supports CSV and XLSX inputs on the documented Windows x64 and macOS Apple
Silicon package targets. Linux packaging is not yet verified. Platform signing limitations and
checksum instructions are documented in each release.

## Security and conduct

- Report security-sensitive concerns privately through [Security](SECURITY.md).
- Report private conduct concerns through the path in the [Code of Conduct](CODE_OF_CONDUCT.md).
- Do not put credentials, personal information, confidential files, or real datasets in a public
  issue, pull request, screenshot, or log.
