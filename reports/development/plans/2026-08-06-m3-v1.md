# M3 (v1.0) Implementation Plan

**Goal:** Add explicit first-digit, second-digit, and combined analysis modes while preserving
the existing first-digit API and keeping every calculation local and user-triggered.

**Architecture:** Follow ADR-009 and the accepted M3 analysis-mode design. Generalize the
analysis engine first, then introduce one immutable controller snapshot, reusable result UI,
mode-aware HTML export, and finally measure large-dataset performance. Existing first-digit
entry points remain compatibility wrappers throughout.

**Tech stack:** Python 3.11, Pandas, NumPy, SciPy, PySide6, Matplotlib, pytest, Ruff, mypy.
No new dependency is planned.

## Global constraints

- Never transmit source data or derived values; all processing remains local and in memory.
- File, sheet, column, preprocessing options, and analysis mode remain explicit user choices.
- Do not assert whether Benford's Law applies to a dataset.
- User-facing copy must remain neutral and must not use restricted accusatory wording.
- Never modify the user's source CSV/XLSX file.
- Keep the analysis engine free of PySide6 imports.
- Preserve `BenfordResult`, `first_digit()`, `expected_first_digit_distribution()`,
  `analyze_first_digit()`, and the existing first-digit drill-down call.
- Each task must leave Ruff, mypy, and the full test suite passing with at least 80% coverage.

## Implementation tasks

### TASK-018: Neutral wording compliance cleanup

**Files:** result summary UI, HTML report, EN/KO/ZH/JA translation catalogs, matching tests.

- Replace the restricted term identified by ISS-002 with neutral exploratory wording.
- Keep UI and HTML report messages aligned in every supported language.
- Regenerate `.qm` catalogs and add regression coverage for all user-facing outputs.
- Mark ISS-002 resolved.

### TASK-019: Shared digit analysis engine

**Files:** `analysis/benford.py`, `tests/analysis/test_benford.py`.

- Add `DigitPosition`, `CombinedBenfordResult`, `second_digit()`,
  `expected_second_digit_distribution()`, `analyze_second_digit()`, and
  `analyze_combined()`.
- Share finite/non-zero normalization and bucket aggregation internally.
- Calculate both positions in one iteration for combined analysis.
- Cover boundary values, scientific notation, negative values, empty input, probability
  reference values, and first-digit compatibility.

### TASK-020: Position-generic expert statistics

**Files:** `analysis/expert_statistics.py` and tests.

- Make MAD and Chi-square derive bucket order from each result instead of assuming 1-9.
- Expose per-position statistics and one shared log-mantissa KS result for combined mode.
- Preserve `calculate_expert_statistics()` compatibility.

### TASK-021: Immutable mode-aware controller snapshot

**Files:** `ui/controller.py` and controller tests.

- Add `AnalysisMode` and one immutable snapshot containing the exact preprocessing,
  suitability, results, statistics, and row-to-digit mappings from one run.
- Invalidate the snapshot when its source choices change.
- Add position-aware drill-down and keep the old first-digit wrapper.

### TASK-022: Reusable result panels and combined layout

**Files:** chart helpers, a reusable digit-result panel, main window, and UI tests.

- Generalize chart buckets and click validation while preserving the first-digit wrapper.
- Add an explicit mode selector.
- Show one panel for single modes and both panels side by side for combined mode.
- Show per-position MAD/Chi-square and only one shared KS result.

### TASK-023: Mode-aware HTML report and existing-language coverage

**Files:** report generator, translation catalogs, report/UI tests.

- Render the selected mode from the same controller snapshot.
- In combined mode, render two labeled result sections while shared context appears once.
- Complete all new strings for EN/KO/ZH/JA and regenerate `.qm` catalogs.

### TASK-024: Large-dataset performance verification

**Files:** profiling notes/benchmarks and only the implementation paths proven necessary.

- Establish representative large-column benchmarks for preprocessing and all modes.
- Confirm combined mode avoids duplicate preprocessing and duplicate digit passes.
- Optimize only measured bottlenecks and record before/after results.

### TASK-025: Spanish and French language expansion

- Compile and package both `.qm` files and verify message/placeholder completeness.

### TASK-026: Russian language expansion
